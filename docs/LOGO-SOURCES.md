## Website implementation rule

1. Use official files only when the source explicitly provides them for reuse, or permission has been obtained.
2. Preserve original aspect ratio, color, clear space, and minimum-size rules.
3. Do not redraw, recolor, crop, or imitate official marks.
4. If permission is unclear, use the existing neutral InstitutionMark / MunicipalityMark / ServiceMark and link to the official source.
5. Keep a source/usage record for every official asset committed to the repository.
