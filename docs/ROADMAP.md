# Website Roadmap

## MVP — sebelum kepengurusan resmi

- Homepage dan identitas sementara
- Struktur navigasi
- Halaman Tentang, Hidup di Ishikawa, Komunitas, Program, Sumber Daya, Kontak
- Responsive layout
- GitHub Pages deployment
- Tidak menyimpan data pribadi

## V1 — setelah kepengurusan resmi

- Logo dan brand system resmi
- Struktur pengurus 2026/27
- Visi, misi, dan program kerja
- Kanal kontak resmi
- Agenda kegiatan
- Survival Guide versi awal
- Halaman flagship program

## V2 — setelah konten stabil

- News / articles berbasis Markdown
- Arsip kegiatan
- Direktori resources
- Statistik anggota dalam bentuk agregat
- Bahasa Inggris untuk halaman publik utama
- Bahasa Jepang untuk halaman kolaborasi/event utama

## V3 — bila benar-benar diperlukan

- Form terintegrasi
- CMS ringan / Git-based editing
- Search
- Interactive map untuk panduan housing/places

Catatan: login anggota dan database tidak menjadi prioritas sampai ada kebutuhan yang jelas.
